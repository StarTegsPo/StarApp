# 🐝 Улей: Нижний ярус — Глава 4 «Гнездо»

Кооперативный хоррор для Roblox (1–8 игроков) в жанре «коридоров»: тёмный лабиринт-улей,
существо-рой из тысяч насекомых, фонарь с батарейкой, шкафчики для пряток и механика
**«связи» (tether)** — держитесь вместе, чтобы выжить и спасать друг друга.

Карта строится скриптом из обычных деталей, поэтому **никаких ассетов не нужно** — игра
работает в пустом плейсе сразу после открытия.

## Как запустить

### Вариант 1 — готовый файл (проще всего)
1. Скачайте `HiveCorridors.rbxlx` из этой папки.
2. Откройте его в **Roblox Studio** (File → Open from File).
3. Нажмите **Play** (или **Test → Start** с 2–3 игроками, чтобы проверить кооп).
4. Опубликуйте: File → Publish to Roblox.

### Вариант 2 — Rojo (для разработки)
```bash
rojo serve        # в этой папке, затем «Connect» в плагине Rojo в Studio
# или
rojo build -o HiveCorridors.rbxlx
```

После правок в `src/` можно пересобрать файл без Rojo: `python3 tools/build_place.py`.

## Геймплей

| | |
|---|---|
| 🎯 Цель | Найти **3 предохранителя** в тупиках улья, вставить их в **генератор** у входа и добраться до **лифта** в самой дальней точке лабиринта |
| 🔦 Фонарь `F` | Батарейка садится. Включённый фонарь рой видит издалека. Батарейки (голубые) лежат по уровню |
| 🏃 Бег `Shift` | Тратит дыхание. **Рой слышит бег.** После полного истощения бегать нельзя, пока не отдышишься |
| 🚪 Шкафчики `E` | Спрятаться и смотреть сквозь щель. Если рой видел, как ты залез, — может вытащить |
| 🔗 Связь | Напарник рядом (22 стада) → дыхание восстанавливается быстрее, фонарь садится медленнее |
| 🕸 Кокон | Пойманного игрока рой уносит в кокон. У команды 40 сек, чтобы найти светящийся кокон и вырвать его (удерживать `E`). Если спасать некому — смерть |
| 😡 Ярость | Каждый вставленный предохранитель ускоряет рой. Когда лифт запитан, свет становится красным, а рой — ещё быстрее |
| ⏱ Время | 8 минут на раунд. Каждый раунд — новый лабиринт |

На телефоне появляются кнопки «Бег» и «Фонарь», на геймпаде — `L3` и `Y`.

## Что внутри

```
src/
  shared/Config.luau          все настройки: размеры лабиринта, скорости, тайминги, звуки
  server/init.server.luau     цикл раундов, предметы, шкафчики, коконы, генератор, лифт
  server/MapBuilder.luau      генерация лабиринта (backtracker + петли), лобби, декор
  server/Monster.luau         ИИ роя: блуждание, слух, зрение, погоня, поиск пути по клеткам
  client/init.client.luau     фонарь, бег, «связь», интерфейс, страх, скримеры, титры
tools/build_place.py          сборка .rbxlx без Rojo
```

## Настройка

Всё меняется в `src/shared/Config.luau`: размер лабиринта, число предохранителей и
шкафчиков, скорость роя, длительность раунда, радиус связи и т.д.

**Звуки.** Чтобы не подставлять чужие ID наугад, звуки по умолчанию выключены.
Найдите в Studio (Toolbox → Audio) жужжание, сердцебиение, скример и эмбиент и вставьте
их ID в `Config.Sounds`, например `Buzz = "rbxassetid://1234567"` — всё остальное
подключится автоматически.

## Важно

- Скорость бега считается на клиенте (как в большинстве хорроров Roblox). Для публичной игры
  стоит добавить серверную проверку скорости от читеров.
- Скрипт удаляет все `SpawnLocation` из шаблона: игроки появляются в лобби, а лабиринт
  строится на высоте 100 стадов над Baseplate.
