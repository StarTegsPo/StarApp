Голос: RHVoice «Артемий» + обработка (EQ, компрессор, лёгкая реверберация). Фоновая lo-fi музыка сгенерирована (`music.py`, без авторских прав) и приглушается под голосом.

Сменить голос: `VOICE=anna python3 make.py` — варианты слушать в `voice_samples.mp3`:
1 aleksandr-hq, 2 artemiy, 3 mikhail, 4 yuriy, 5 vitaliy, 6 pavel, 7 evgeniy-rus, 8 anna, 9 elena, 10 irina, 11 tatiana, 12 victoria, 13 arina.

Советы: публикуй вечером (18:00–21:00), первое видео — интро.

## Пересборка
```bash
sudo apt install rhvoice rhvoice-russian ffmpeg && pip install pillow
python3 make.py   # тексты и озвучка — в videos.json
```
