Готовые файлы: `out/startegs_tiktok_01.mp4` … `out/startegs_tiktok_10.mp4`.
1080×1920, 30 fps, H.264 + AAC, 14–19 с. Музыка синтезирована с нуля (`music.py`), так что проблем с авторскими правами не будет.

## Как пересобрать

```bash
cd promo/tiktok
node render.cjs --preview      # раскадровки → out/preview/NN.jpg
PAR=3 node render.cjs          # все 10 видео (или: node render.cjs 03 07)
```

Нужны Node + Playwright (Chromium), ffmpeg, Python 3 с numpy.
- `videos.js` — сценарии (сцены, тексты, тайминги), меняются без программирования;
- `engine.js` — покадровый движок анимации (кадр зависит только от времени, поэтому рендер точный);
- `style.css` — оформление; `music.py` — бит под BPM ролика, удары синхронизированы со склейками.
