# Бот продажи курса «Нейросети на практике»

Один файл `main.py` без зависимостей (Python 3.8+) + `course.pdf` (сам курс, 14 стр.) + `cover.jpg` (обложка).

## Как работает

1. `/start` → обложка, описание курса, кнопки **💳 Купить за 149₽**, **📖 Программа**, **💬 Вопрос**.
2. «Купить» → номер карты (копируется нажатием) и инструкция.
3. «✅ Я оплатил» → клиент присылает скриншот чека.
4. Админу приходит чек с кнопками **✅ Подтвердить / ❌ Отклонить**.
5. «Подтвердить» → бот сам отправляет клиенту PDF. Купившим в меню доступна кнопка «📥 Скачать курс».
6. Вопросы клиентов приходят админу, ответ — реплаем на сообщение.

Команды админа: `/start` (панель), `/stats`, `/give <id>`, `/to <id> <текст>`, `/test`.
