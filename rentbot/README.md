# Бот аренды товаров

Один файл `main.py`, без зависимостей — нужен только Python 3.8+.

## Как работает

1. `/start` → «👋 Приветствую в нашем боте!» и кнопка **🛒 Выбрать товар**.
2. Товары: **Пасик2**, **Хрос6**, **ХироQ** — цена 10₽ за 1 шт.
3. Клиент выбирает количество (1–10 кнопками или «✏️ Другое количество»).
4. Пишет место встречи → заявка приходит админу: имя, @username, ID, товар, кол-во, сумма, место.
5. Админ **отвечает реплаем** (свайп / «Ответить») на заявку или сообщение клиента — ответ приходит клиенту.
   Клиент пишет в ответ — сообщение снова приходит админу. И так далее. Фото, голосовые, геолокация тоже пересылаются.
   `/to <id> <текст>` — написать клиенту по ID.

Список товаров и цена — константы `PRODUCTS` и `PRICE` в начале `main.py`.

## Запуск (Termux / любой Linux)

```bash
cd rentbot
cp .env.example .env    # впишите BOT_TOKEN
python main.py
```

Затем со своего аккаунта отправьте боту `/admin` — вы станете админом (или укажите `ADMIN_ID` в `.env`).
Данные (админ, связки сообщений, номера заявок) хранятся в `rentbot_data.json` рядом с файлом.

Для запуска вместе с остальными ботами в Termux раскомментируйте строку `rentbot` в `termux/bots.conf`.

## Ошибка 103 / нет связи с Telegram

Значит, провайдер обрывает соединения с Telegram. Включите VPN на телефоне (Termux пойдёт через него) и перезапустите бота.
Или пропишите прокси в `.env`: `PROXY=http://адрес:порт`. Бот и так подключается только по IPv4 и сам переподключается при обрывах.
