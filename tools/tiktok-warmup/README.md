# TikTok Warmup

Листает ленту «Для вас» в окне Chromium и ставит лайк через случайное число роликов (по умолчанию от 1 до 18).
Время просмотра каждого ролика тоже случайное, иногда делаются паузы.

## Запуск (на компьютере: Windows / macOS / Linux, Node.js 18+)

```bash
cd tools/tiktok-warmup
npm install
npx playwright install chromium
npm start
```

1. Откроется окно браузера с TikTok. Войдите в свой аккаунт (один раз — сессия сохранится в папке `profile/`).
2. Закройте всплывающие окна, оставьте открытой ленту «Для вас».
3. Нажмите Enter в терминале — скрипт начнёт листать и лайкать. Остановить: Ctrl+C.

## Настройки

```bash
node warmup.js --videos=200 --like-min=1 --like-max=18 --watch-min=5 --watch-max=25 --break-every=40
```

| Флаг | По умолчанию | Что делает |
|---|---|---|
| `--videos` | 120 | сколько роликов пролистать за запуск |
| `--like-min` / `--like-max` | 1 / 18 | лайк через случайное число роликов из этого диапазона |
| `--watch-min` / `--watch-max` | 5 / 25 | сколько секунд смотреть каждый ролик |
| `--break-every` | 40 | примерно через сколько роликов делать паузу |
| `--break-min` / `--break-max` | 30 / 120 | длительность паузы, сек |

## Важно

- Автоматизация нарушает правила TikTok. Если платформа распознает бота, аккаунт может получить теневой бан или блокировку — эффект, обратный прогреву. Не ставьте слишком много роликов за раз и не гоняйте скрипт круглосуточно.
- Если TikTok поменяет вёрстку и в логе появится «кнопка лайка не найдена», нужно обновить селекторы в функции `findActiveLike`.
