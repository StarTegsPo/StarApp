# TikTok Warmup — версия для телефона (Android + Termux)

Скрипт сам листает ленту в приложении TikTok и ставит лайк через случайное число роликов (1–18).
Ни root, ни компьютер не нужны: телефон управляет сам собой через «Отладку по Wi-Fi» (Android 11+).

## 1. Установка (один раз)

1. Поставьте **Termux** из F-Droid (версия из Google Play устарела). По желанию — **Termux:API** (не даёт телефону усыпить скрипт).
2. В Termux:
   ```bash
   pkg update -y && pkg install -y android-tools git termux-api
   git clone -b ccr-ae00cfe2-ced7kn https://github.com/StarTegsPo/StarApp.git
   ```
3. Включите режим разработчика: *Настройки → О телефоне* → 7 раз нажмите «Номер сборки».
4. *Настройки → Для разработчиков* → включите **«Отладка по Wi-Fi»** (телефон должен быть подключён к Wi-Fi).

## 2. Подключение adb к самому телефону

Удобнее всего в режиме разделённого экрана: сверху Termux, снизу настройки.

1. В «Отладке по Wi-Fi» нажмите **«Подключить устройство с помощью кода»** — появятся код и порт (например `192.168.1.5:37123`, код `482913`).
2. В Termux:
   ```bash
   adb pair localhost:37123 482913
   ```
3. Закройте окно с кодом. На экране «Отладка по Wi-Fi» вверху есть **другой** порт («IP-адрес и порт», например `:41055`):
   ```bash
   adb connect localhost:41055
   adb devices        # должно быть: localhost:41055  device
   ```

`adb pair` нужен только один раз. После перезагрузки телефона или выключения Wi-Fi повторяйте только `adb connect` (порт меняется — смотрите его в настройках).

## 3. Запуск

```bash
cd StarApp/tools/tiktok-warmup/termux
bash warmup.sh --check     # проверить, что сердечко находится
bash warmup.sh             # запуск
```

Скрипт сам откроет TikTok. Через 10 секунд он начнёт листать. Termux останется работать в фоне.
Остановить: откройте Termux и нажмите **Ctrl+C** (кнопка CTRL на панели клавиш, затем C).

## Настройки

```bash
bash warmup.sh --videos=200 --like-min=1 --like-max=18 --watch-min=5 --watch-max=25
```

| Флаг | По умолчанию | Что делает |
|---|---|---|
| `--videos` | 120 | сколько роликов пролистать |
| `--like-min` / `--like-max` | 1 / 18 | лайк через случайное число роликов |
| `--watch-min` / `--watch-max` | 5 / 25 | секунд смотреть каждый ролик |
| `--break-every` | 40 | примерно каждые N роликов перерыв |
| `--break-min` / `--break-max` | 30 / 120 | длина перерыва, сек |
| `--like-x` / `--like-y` | — | координаты сердечка вручную |
| `--check` | — | только проверить поиск сердечка |

## Если сердечко не находится

Некоторые версии TikTok не отдают экран для автопоиска. Тогда задайте координаты вручную:
1. *Для разработчиков* → включите **«Расположение указателя»**.
2. Откройте TikTok, нажмите на сердечко и запомните X и Y в верхней строке.
3. Выключите «Расположение указателя» и запускайте так: `bash warmup.sh --like-x=990 --like-y=1250`.

С ручными координатами скрипт не видит, стоит ли уже лайк. Если ролик уже был лайкнут, лайк снимется. В ленте рекомендаций такое бывает редко.

## Важно

- TikTok запрещает автоматизацию. Если платформа распознает бота, возможен теневой бан. Не гоняйте скрипт часами без перерыва.
- Пока скрипт работает, не трогайте экран: свайпы и нажатия идут на тот экран, что открыт сейчас.
