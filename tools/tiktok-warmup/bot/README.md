# Бот «Прогрев TikTok»

Telegram-бот, который:
- выдаёт приложение (APK последней сборки из релиза `warmup-latest`, файл кешируется в Telegram);
- продаёт Premium за Telegram Stars (по умолчанию 50 ⭐) и сразу присылает код активации;
- хранит коды покупателя в «🎟 Мои коды»;
- принимает вопросы в поддержку и пересылает их администратору (ответ — reply на пересланное сообщение).

Без внешних библиотек: нужен только Python 3.9+.

## Настройка

```bash
cd ~/StarApp/tools/tiktok-warmup/bot
cp .env.example .env
nano .env        # BOT_TOKEN, ADMIN_IDS, CODE_SEED
python bot.py    # проверить вручную, Ctrl+C — остановить
```

Автозапуск вместе с остальными ботами: строка `tiktokwarmup` уже есть в `termux/bots.conf`,
дальше `bash ~/StarApp/termux/start_all.sh`.

`CODE_SEED` нельзя менять: приложение знает только коды, полученные из этого секрета.
Если его потерять или сменить, выданные коды продолжат работать, а новые — нет.

Если тот же токен уже использует другой запущенный бот, в логе будет `Conflict` — остановите старый.

## Команды администратора

| Команда | Что делает |
|---|---|
| `/admin` | список команд |
| `/stats` | пользователи, продажи, звёзды, остаток кодов |
| `/code` | код Premium себе |
| `/gift ID` | подарить код (или ответом на сообщение пользователя из поддержки) |
| `/broadcast текст` | рассылка всем пользователям |
| `/refund ID charge_id` | вернуть звёзды (данные есть в уведомлении о продаже) |

Данные бота (пользователи, выданные коды) — в `data.json` рядом с ботом.
