# StarTegs Hub — один бот вместо четырёх

Заменяет @StarTegsEcosistem_bot, @StarTegsAi_bot, @StarTegsShop_bot и @StarTegsBuisnes_bot.
Работает в Telegram, в мини-приложении в стиле iOS («жидкое стекло») и как связующее звено для приложения StarTegs.

## Что умеет

| В Telegram | |
|---|---|
| 🗑 Удалённые и правки | Через Telegram для бизнеса: присылает удалённые сообщения (текст, фото, видео, голосовые, кружки, стикеры) и правки «было → стало» из твоих личных чатов. `/deleted`, `/find слово` |
| 🤖 Звёздочка | Нейросеть с памятью диалога: просто напиши текст. `/new` — новый диалог, `/tr en текст` — перевод, пересланное длинное сообщение — краткий пересказ |
| 🛍 Маркет | `/sell` — объявление с фото за 5 шагов, `/market` — лента, `/my` — мои, избранное, кнопка «Написать продавцу» |
| 📊 Аналитика | Добавь бота админом в канал/группу: подписчики, рост за сутки/неделю/месяц, пришли/ушли, посты, лучшее время. `/stats` |
| ⏰ Напоминания | `/remind 30m текст`, `/remind 2h`, `/remind 18:30 текст` |
| 📝 Заметки | `/note текст`, `/notes` |
| 📈 Моя статистика | `/me` — неделя в чатах: получено/отправлено, топ собеседников, кто чаще удаляет, пик активности |
| 📤 Экспорт | `/export` — красивый HTML-файл с архивом удалённых и правок (30 дней, с Gold — весь) · `/edits` — последние правки |
| 🌙 Итоги дня | Вечером (`DIGEST_HOUR`, по умолчанию 21:00) — сколько удалили и изменили за день. `/digest` — вкл/выкл |
| 👑 StarTegs Gold | `/gold` — 49 ⭐ / 30 дней, `/trial` — 3 дня бесплатно (один раз), `/invite` — +3 дня за каждого нового друга (до 30) |
| 👑 Админка | `/admin` — статистика, `/broadcast текст` — рассылка с подтверждением, `/refund ID платёж` — вернуть звёзды |

| Мини-приложение | |
|---|---|
| 🏠 Главная | Приветствие, сводка удалённых за сегодня, Gold и пробный период, «Твоя неделя» с графиками, приглашение друзей, плитки |
| 🗑 Удалённые | Поиск, вкладка «Изменённые» с подсветкой «было → стало» |
| ✨ ИИ | Чат со Звёздочкой, подсказки-идеи, «Новый чат» |
| 🛍 Маркет | Поиск, категории, «Мои», «Избранное», объявление из шторки |
| ⚙️ Ещё | Графики каналов, напоминания, заметки, настройки, очистка архива |

Дизайн: живой градиентный фон, стеклянные карточки с размытием, плавающая панель вкладок, всплывающие шторки,
пружинящие нажатия, вибрация Telegram, светлая и тёмная тема, анимации появления.

**Для приложения StarTegs** (тот же протокол `POST /api`, что у старого бота): друзья со StarTegs видят твою рамку,
значок, цвет и шрифт имени, витрину; облачный архив удалённых; нейросеть без своего ключа.
Всё бесплатно; StarTegs Gold добавляет «выделяющие» фишки (золотое имя ✦, рамки, эффекты, стили) и лимиты побольше.

## Запуск в Termux

```bash
curl -fsSL https://raw.githubusercontent.com/StarTegsPo/StarApp/claude/startegs-whitegram-features-cdjfn9/termux/hub.sh -o ~/hub.sh
bash ~/hub.sh setup <ТОКЕН_БОТА> <ТВОЙ_ID>
bash ~/hub.sh key        # нейросеть: 1 — OpenRouter бесплатно
bash ~/hub.sh start
```

Совет: возьми токен старого @StarTegsEcosistem_bot (и останови старого бота: `bash ~/startegs-run/stop_all.sh startegs`) —
тогда приложение StarTegs подключится к Hub само, без пересборки.

Команды: `bash ~/hub.sh status | logs | restart | stop | update`.

### Включить «Удалённые»
1. @BotFather → твой бот → Bot Settings → **Business Mode** → включить.
2. Telegram → Настройки → **Telegram для бизнеса** → **Чат-боты** → выбрать бота (нужен Telegram Premium).

### Аналитика
Добавь бота **администратором** в канал или группу. Снимок числа подписчиков — раз в 3 часа.

## Разработка

```bash
pip install -r requirements.txt
python -m unittest test_hub -v      # тесты без Telegram
BOT_TOKEN=… ADMIN_ID=… PUBLIC_URL=https://… python bot.py
```

Файлы: `bot.py` — бот и веб-сервер, `ai.py` — нейросеть, `db.py` — база SQLite (`hub.db`), `webapp/index.html` — мини-приложение.
