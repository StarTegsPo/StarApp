# ⭐ StarApp — бизнес-помощник в Telegram

Бот + Telegram Mini App, внутри которого собраны все сервисы:

| Сервис | Что делает |
|---|---|
| 🌐 **StarTegs** | «StarTegs для iPhone»: боты экосистемы, палитры и сезонные эффекты, шаблоны ответов, заметки (см. ниже) |
| 🚀 **Хаб** | Все ИИ в одном чате (Claude, ChatGPT, Gemini, DeepSeek, Grok, Mistral, OpenRouter) и сравнение ответов, TikTok/YouTube/Instagram и другие соцсети во встроенном браузере Telegram, контент-студия, автоматизации по расписанию (см. ниже) |
| 🏠 **Главная** | Живая лента событий (новые подписчики, продажи, ответы поддержки, друзья) с автообновлением, ежедневный бонус с серией дней, уровни и достижения, реферальная программа |
| 📊 **Аналитика** | Каналы (подписчики, рост, приход/отток, посты, форматы, активные часы), боты (DAU, новые пользователи, события, конверсия в покупку), покупки (выручка, заказы, средний чек, топ товаров) |
| 🛍 **Магазин** | Каталог услуг, оплата в Telegram Stars или с внутреннего баланса, история покупок, управление товарами для админов |
| 👤 **Профиль** | Баланс, пополнение через Stars, история операций |
| 💬 **Поддержка** | Тикеты из приложения или `/support`, уведомления админам, ответ реплаем прямо в Telegram |

Внешних зависимостей нет: Node.js 22.13+ (встроенные `node:sqlite`, `fetch`, `node:test`), чистый JS в Mini App.

## Запуск

```bash
cp .env.example .env    # заполните BOT_TOKEN, PUBLIC_URL, ADMIN_IDS
npm start               # бот (long polling) + HTTP-сервер с API и Mini App
npm test
```

1. Создайте бота в [@BotFather](https://t.me/BotFather) и вставьте токен в `BOT_TOKEN`.
2. Mini App должен быть доступен по **HTTPS**: укажите адрес в `PUBLIC_URL`. Для локальной разработки подойдёт туннель (ngrok, cloudflared) на `PORT`.
   При старте бот сам ставит кнопку меню «StarApp» и команды.
3. `ADMIN_IDS` — ваши Telegram ID (видят продажи магазина, добавляют товары, отвечают в поддержке).
   `SUPPORT_CHAT_ID` — группа, куда падают тикеты (иначе — в личку админам).
4. Чтобы открыть Mini App в обычном браузере без Telegram, задайте `DEV_USER_ID` (не работает при `NODE_ENV=production`).

## StarTegs для iPhone

На iPhone нельзя поставить Android-мод клиента StarTegs, поэтому похожие возможности собраны в Mini App — на первой вкладке **🌐 StarTegs**:

- **Сервисы экосистемы**: StarTegs (@StarTegsEcosistem_bot — удалённые сообщения, архив, Premium), Маркет (@StarTegsShop_bot), ИИ-ассистент (@StarTegsAi_bot) и Бизнес-аналитика (вкладка этого приложения). Кнопка «Открыть» вызывает `Telegram.WebApp.openTelegramLink('https://t.me/<бот>?startapp')`, вне Telegram — `window.open`.
  Список задаётся переменной `ECO_BOTS` (JSON-массив `{icon, title, desc, bot}` или `{icon, title, desc, tab}` для вкладки приложения), по умолчанию — константа `DEFAULT_ECO_BOTS` в `src/services/eco/index.js`.
- **Android-версия**: ссылка на полный мод клиента — https://github.com/StarTegsPo/StarApp/releases/tag/client-latest
- **Оформление** (раздел «Стиль»): палитры Фиолет (по умолчанию), Неон, Золото, Изумруд, Закат и «Своя» с 12 оттенками — меняют CSS-переменные `--a1/--a2/--a3/--grad` во всём приложении. Сезонные эффекты: Выкл (по умолчанию) / Авто / ❄️ Снег / 🍂 Листопад / 🌸 Лепестки / ✨ Светлячки. «Авто»: дек–фев снег, мар–май лепестки, июн–авг светлячки, сен–ноя листья. Эффект рисуется на canvas поверх страницы (`pointer-events: none`), при «Уменьшении движения» (`prefers-reduced-motion`) не анимируется.
  Настройки хранятся на сервере (таблица `eco_settings`) и в `localStorage`, применяются при старте (`webapp/theme.js`).
- **Шаблоны ответов**: название (до 100 символов) + текст (до 2000), не больше 50 на пользователя, копирование одним нажатием.
- **Заметки**: заголовок + текст (до 10 000 символов), создание, редактирование, удаление.

API (все маршруты требуют авторизации, чужие данные недоступны — 404):

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/eco` | боты экосистемы, ссылка на Android, настройки, число шаблонов и заметок, лимиты |
| GET / POST | `/api/eco/settings` | получить / частично обновить `{ palette, hue, effect }` |
| GET / POST | `/api/eco/templates` | список / создать `{ title, text }` |
| DELETE | `/api/eco/templates/:id` | удалить шаблон |
| GET / POST | `/api/eco/notes` | список / создать `{ title, text }` |
| GET / POST / DELETE | `/api/eco/notes/:id` | получить / обновить / удалить заметку |

## 🚀 Хаб — все ИИ и соцсети, не выходя из Telegram

Вкладка **Хаб** разделена на четыре экрана:

- **💬 ИИ** — один чат для всех нейросетей. ИИ переключается прямо посреди диалога (новый видит всю переписку), режим **⚖️ Сравнить** отправляет вопрос сразу до 4 ИИ параллельно. История диалогов хранится на сервере. Ниже — быстрые ссылки на сайты ИИ-сервисов (Midjourney, CapCut, ElevenLabs, Canva…).
- **🎬 Студия** — готовые пресеты: идеи для TikTok, сценарий ролика по секундам, описание + хэштеги, ответ на комментарий, пост для Telegram, контент-план на неделю, перевод. Результат можно скопировать, доработать в чате или сразу открыть загрузку в TikTok.
- **📱 Соцсети** — TikTok, YouTube, Instagram, X, ВКонтакте, Threads, Twitch, Pinterest с быстрыми действиями (загрузить видео, статистика, директ). Ссылки открываются во встроенном браузере Telegram (`Telegram.WebApp.openLink`), вход в аккаунты сохраняется. Превью роликов по ссылке TikTok/YouTube (официальный oEmbed) + «💡 Идеи по мотивам» и «✍️ Описание» одной кнопкой.
- **⚡ Авто** — автоматизации по расписанию (время, дни недели, часовой пояс пользователя): задание для ИИ («каждое утро 5 идей для TikTok») или напоминание («19:00 — выложить ролик»). Результат приходит сообщением от бота. Есть шаблоны, пауза и «Запустить сейчас».

В самом боте: `/ai вопрос` — ответ первого подключённого ИИ прямо в чате.

**Подключение ИИ.** Ключи задаются на сервере в `.env` (`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY`, `DEEPSEEK_API_KEY`, `XAI_API_KEY`, `MISTRAL_API_KEY`, `OPENROUTER_API_KEY`) — пользователю ничего вводить не нужно, ключи не передаются в Mini App. Без ключа провайдер показывается серым. Модель меняется переменной `<ID>_MODEL` (например, `CLAUDE_MODEL`). `HUB_DAILY_LIMIT` — ИИ-запросов в день на пользователя (по умолчанию 50, админы без лимита). Запросы к API — обычный `fetch`, без SDK, чтобы сохранить проект без зависимостей; для Claude включён серверный `fallbacks: "default"` (при отказе по политике безопасности запрос автоматически повторяется на подходящей модели).

**Ограничения платформ.** Публиковать в TikTok/Instagram от имени пользователя через API можно только после одобрения приложения в TikTok for Developers / Meta, поэтому сейчас хаб открывает нужные страницы этих сервисов во встроенном браузере, а не постит сам.

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/hub` | провайдеры (включён/нет), соцсети, пресеты, расход лимита |
| POST | `/api/hub/ask` | `{ text, provider?, chatId?, preset? }` → `{ chatId, reply, provider }` |
| POST | `/api/hub/compare` | `{ text, providers? }` → ответы нескольких ИИ |
| GET / DELETE | `/api/hub/chats`, `/api/hub/chats/:id` | история диалогов |
| GET | `/api/hub/preview?url=` | превью ролика TikTok / YouTube |
| GET / POST | `/api/hub/tasks` | автоматизации: список / создать `{ title, kind: ai\|remind, prompt, provider?, time: "ЧЧ:ММ", days: маска пн=1…вс=64, tzOffset }` |
| POST / DELETE | `/api/hub/tasks/:id` | изменить (в т.ч. `{ enabled }`) / удалить |
| POST | `/api/hub/tasks/:id/run` | выполнить сейчас |

## Рефералы и бонусы

- Ссылка-приглашение: `https://t.me/<бот>?start=ref_<ID>`. Она есть на главном экране Mini App, с кнопкой «Поделиться».
- Пригласивший получает `REFERRAL_BONUS` ⭐ (по умолчанию 10), когда друг совершит **первую оплату**. Бонус начисляется один раз, пригласить самого себя нельзя.
- Ежедневный бонус даёт опыт (XP), а не звёзды, поэтому бесплатно получить деньги на балансе нельзя. Уровень складывается из опыта за серию дней и полученных достижений.

## Как собирается аналитика

- **Каналы и группы.** Добавьте бота администратором. Он запоминает, кто его добавил (это владелец статистики), раз в `CHANNEL_SNAPSHOT_MINUTES` снимает число подписчиков, записывает посты (`channel_post`) и подписки/отписки (`chat_member`).
- **Ваши боты.** В приложении: Аналитика → Боты → «Получить API-ключ». Затем отправляйте события из бота:
  ```bash
  curl -X POST https://your-domain/api/track -H 'content-type: application/json' \
    -d '{"api_key":"KEY","user_id":123,"event":"start"}'
  # покупка: "event":"purchase","amount":150
  # пакетом: {"api_key":"KEY","events":[{...},{...}]}
  ```
- **Покупки.** События `purchase` ваших ботов плюс (для админов) продажи магазина StarApp.

## Команды бота

`/start`, `/stats`, `/balance`, `/support текст`, `/help`. Для админов: `/addproduct Название | цена | описание`, `/close N`, а также ответ реплаем на тикет.

## Структура

```
src/
  index.js            точка входа
  app.js              сборка: бот, платежи Stars, API, сервисы
  telegram.js         минимальный клиент Bot API (long polling, команды, роутинг апдейтов)
  http.js             HTTP-сервер, роутер, авторизация по initData, статика
  auth.js             проверка подписи initData Mini App
  db.js               SQLite, пользователи, баланс, транзакции
  services/
    index.js          реестр сервисов и контракт
    analytics/        аналитика каналов, ботов, покупок (queries.js — SQL-отчёты)
    eco/              «StarTegs для iPhone»: экосистема, оформление, шаблоны, заметки
    hub/              Хаб: ИИ-провайдеры (providers.js), соцсети, студия, автоматизации
    shop/  profile/  support/
webapp/
  index.html, app.js, style.css    ядро Mini App (тема Telegram, навигация, графики)
  theme.js                          палитры и сезонные эффекты
  services/<id>.js                  экран каждого сервиса
test/                               тесты API, платежей, поддержки, аналитики
```

### Как добавить новый сервис

1. `src/services/<id>/index.js`: объект `{ id, title, icon, order, migrations, setupBot, setupApi, onPayment, validatePayment, start }`, подробности в `src/services/index.js`.
2. Добавьте его в массив `services` в `src/services/index.js`.
3. `webapp/services/<id>.js` с `export async function render(el, app)`.

Вкладка появится в Mini App автоматически. Платежи маршрутизируются по префиксу payload `"<id>:..."`.
