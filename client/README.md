# ⭐ StarTegs — мод клиента Telegram для Android

Неофициальный клиент на основе [исходного кода Telegram для Android](https://github.com/DrKLO/Telegram) (GPL v2+).
Ставится **рядом** с обычным Telegram: у него свой пакет `org.startegs.messenger.web`, своё имя и иконка.

**Ограничения.** Сохраняются сообщения, которые уже были загружены в клиент до удаления. Если Telegram сбросит кэш
канала (например, после долгого офлайна), удалённые сообщения из этого канала пропадут. В секретных чатах мод
ничего не сохраняет.

## Как собрать APK

APK собирается автоматически на серверах GitHub (workflow «Сборка клиента StarTegs») при каждом изменении папки
`client/`. Первая сборка идёт 1–2 часа: компилируется вся нативная часть Telegram.

Готовый файл появляется в релизе **client-latest**:
https://github.com/StarTegsPo/StarApp/releases/tag/client-latest

### Обязательно: свои ключи API

Без них APK соберётся, но войти в аккаунт не получится. Использовать чужие ключи запрещено правилами Telegram.

1. Зайдите на https://my.telegram.org → **API development tools** и создайте приложение (Platform: Android).
2. В репозитории GitHub: **Settings → Secrets and variables → Actions → New repository secret**:
   - `TG_API_ID` — число *App api_id*;
   - `TG_API_HASH` — строка *App api_hash*.
3. Запустите сборку: **Actions → Сборка клиента StarTegs → Run workflow**.

### Желательно: свой ключ подписи

Без него APK подписывается тестовым ключом из исходников Telegram. Им может подписать APK кто угодно,
поэтому для раздачи пользователям сделайте свой ключ (один раз, на любом компьютере с Java):

```bash
keytool -genkeypair -v -keystore startegs.keystore -alias startegs -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 startegs.keystore    # это значение → секрет KEYSTORE_BASE64
```
Пароль от ключа → секрет `KEYSTORE_PASSWORD`. **Сохраните файл ключа.** Без него следующие версии не установятся
поверх старой.

### Сервисы в меню

В `client/startegs.properties` впишите username ваших ботов вместо `ВПИШИТЕ_USERNAME` (без @). Пункты без username
не показываются. Режим `app` сразу открывает главное мини-приложение бота: включите его в @BotFather →
Bot Settings → Configure Mini App. Режим `chat` открывает чат с ботом.

## Как устроен мод

```
client/
  startegs.properties     настройки: имя, пакет, боты, версия Telegram, архитектуры
  src/org/startegs/       весь код мода (StarMod.java)
  patches/apply.py        вставляет вызовы StarMod в исходники Telegram
  res/                    иконка
.github/workflows/client-apk.yml   сборка APK
```

В исходники Telegram вставляются только короткие вызовы `StarMod.*`:
- `MessagesController` — перехват удаления и сохранение прошлых версий при редактировании;
- `ChatMessageCell` — пометка «удалено»;
- `ChatActivity` — пункт «История изменений»;
- `SettingsActivity` — раздел StarTegs и скрытие Premium-блоков;
- `MessagesController.sendTyping` / `completeReadTask` — «печатает» и «прочитано»;
- `DialogsActivity` — скрытие историй.

Фирменные темы делает `patches/brand_theme.py` из встроенных тем Telegram: синие акценты перекрашиваются
в фирменный фиолетово-синий с той же яркостью, поэтому контраст текста не меняется.

Каждая вставка ищет точный фрагмент кода. При обновлении Telegram (`upstream_commit`) скрипт сам скажет,
какие места изменились.

## Бот StarTegs v58

Облачному архиву нужен обработчик в боте: `client/bot/startegs_v58_addon.py`. Он вставляется в `startegs_v57.py`
перед строкой `def _single_instance():`. Целиком файл бота в репозиторий не кладётся: в нём может быть токен.
